1. ПРИМЕЧАНИЕ 1. Для обеспечения демонтажа гильзы размер C должен составлять 610 мм (24″) или полную длину защитной гильзы плюс 76 мм (3″), в зависимости от того, что больше.
  2. ПРИМЕЧАНИЕ 2. Для предотвращения образования карманов на горизонтальном трубопроводе следует предусматривать эксцентрические переходы.
  3. ПРИМЕЧАНИЕ 3. Внутренний диаметр ответвительного присоединения должен быть не менее 1″.
  4. ПРИМЕЧАНИЕ 4. Для некриогенных сред защитную гильзу предпочтительно устанавливать сверху трубопровода. Для криогенных жидкостей, чтобы избежать скопления паров, рекомендуется располагать гильзу в секторе от горизонтальной плоскости до 45° ниже этой точки.
  5. ПРИМЕЧАНИЕ 5. Минимальный размер трубопровода может изменяться в зависимости от глубины штуцера и выбранной длины защитной гильзы. Сведения о технологических трубных присоединениях см. в PIP PNF0200.
  6. ПРИМЕЧАНИЕ 6. С учётом длины чувствительного элемента минимальная глубина для RTD и биметаллических индикаторов должна составлять 75 мм (3″).
