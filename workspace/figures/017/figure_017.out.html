Примечания

ПРИМЕЧАНИЕ 1. Размер от оси отбора до поверхности фланца превышает стандартные 25,4 мм (1,0″), когда применяются спирально-навитые прокладки толщиной 3,2 мм (1/8″). При β ≥ 0,4 для NPS 2″ и 3″, а также при β ≥ 0,65 для размеров NPS 4″ и более следует рассмотреть смещение отбора на 1,59 мм (1/16″) ближе к поверхности фланца. Влияние нестандартного расположения отбора диафрагмы на точность измерения см. в API MPMS, глава 14.3.

ПРИМЕЧАНИЕ 2. Для спирально-навитых прокладок требуется минимальная шероховатость поверхности. Приложение C ASME PCC-1 рекомендует обработку поверхности 3,2–6,4 мкм (128–250 микродюймов).

ПРИМЕЧАНИЕ 3. Для фланцев Class 900 и выше для повышения прочности применялись муфтовые приварные присоединения NPS 3/4.

ПРИМЕЧАНИЕ 4. Отверстие под отжимной винт с соответствующей выемкой в каждом фланце пары предусматривается для разведения фланцев при установке диафрагмы.

ПРИМЕЧАНИЕ 5. Чтобы исключить помехи рукоятке диафрагмы, можно рассмотреть перенос отжимных винтов на один болт от отборов давления.

ПРИМЕЧАНИЕ 6. Диаметр отбора (D) для фланцев диафрагмы размером менее 3″ составляет 6,4 мм (1/4″), а для пары фланцев 3″ — 9,5 мм (3/8″). Эти диаметры должны сохраняться на минимальном расстоянии 2,5D от внутреннего диаметра трубы. В остальных случаях стандартный диаметр отбора составляет 12,7 мм (1/2″).

ПРИМЕЧАНИЕ 7. Если не указано иное, во фланце диафрагмы выполняются два отбора, расположенные под углом 180° друг к другу.

ПРИМЕЧАНИЕ 8. Выполнить гравировку: UPSTREAM (вверх по потоку); измеренный диаметр отверстия; позиционное обозначение прибора; размер фланца; класс давления и тип уплотнительной поверхности; материал диафрагмы; тип диафрагмы. Размер дренажного отверстия, если оно предусмотрено, должен быть указан седьмой строкой.
